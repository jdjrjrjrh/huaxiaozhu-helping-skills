# 静态主机部署说明

## 一、部署前检查

确认主机支持：

- 通过 HTTP 或 HTTPS 访问静态 HTML；
- 上传子目录；
- 默认首页设置为 index.html。

项目不需要数据库、PHP、Python、Node.js、npm或URL重写规则。

## 二、上传方法

将项目根目录中的全部 HTML 文件和 assets 目录完整上传到主机网站根目录，例如 public_html、wwwroot 或 htdocs。

## 三、部署后的检查顺序

1. 打开域名，确认进入欢迎页。
2. 点击“游客体验”，确认进入首页。
3. 分别点击首页、自测、训练、学习、我的。
4. 完成一次自测，确认结果页出现雷达图。
5. 完成一次重述训练，确认评价进入训练记录。
6. 刷新页面，确认本地记录仍然存在。
7. 分别使用手机和电脑访问，检查导航形态是否自动切换。

## 四、子目录部署

本项目使用相对路径，可以部署到域名子目录，例如：

https://example.com/huaxiaozhu/

不要修改 assets 与 HTML 之间的相对位置。

## 五、缓存问题

覆盖旧版本后如果页面仍显示旧内容：

1. 使用无痕窗口重新访问；
2. 清除浏览器缓存；
3. 在主机控制面板清除静态缓存或 CDN 缓存；
4. 确认所有 JS 和 CSS 文件均已覆盖。

## 六、HTTPS

项目本身不强制要求 HTTPS，但正式对外使用时建议在主机控制面板启用 HTTPS。
